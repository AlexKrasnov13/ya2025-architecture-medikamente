# architecture-medikamente

## Короткий свод по задачам

1. `Task1`: выполнен анализ потоков конфиденциальных данных, собраны проблемы As-Is и подготовлены DFD To-Be (L0 + отдельные L1 по процессам).
2. `Task2`: сделана C4-диаграмма целевой архитектуры с Privacy by Design блоками, аналитическим слоем и корректным контуром интеграции лаборатории.
3. `Task3`: подготовлена классификация данных и практический набор защит для at rest/in transit + автоматизированные контроли и реестр средств.
4. `Task4`: построена диаграмма Исикавы, выделены узкие места миграции и предложен приоритизированный план устранения рисков.
